# codebase_indexer
Index code changes for coding agents


make sure for installing chroma, do 
sudo apt update
sudo apt install python3-dev build-essential


The project aims to use merkle trees, ASTs, and vector database to build a codebase indexer locally. Users can use the tool to build ai agents to navigate the coding projects and interface with LLMs to save API token cost. This is a proof of concept project.


In the future, I will build this as VSCode extension using typescript instead.
